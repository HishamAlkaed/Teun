<objective>
Stand up the RAG data layer: add the four crates, create the pgvector-backed
`documents` + `chunks` schema via a new numbered migration, scaffold the `rag`
module with the `Document`/`Chunk` types and insert/get CRUD, and build the
OpenAI (+Azure) embeddings client.

Purpose: Every downstream plan (ingestion, retrieval, answer path) depends on
these contracts — the DB schema, the store types, and the embedding function.
Defining them first prevents a scavenger hunt during ingestion/retrieval.

Output: `003_rag.sql`, `src/rag/{mod,store,embed}.rs`, updated `Cargo.toml`,
`.env.example`, and `main.rs` module registration.
</objective>
