<objective>
Turn an extracted canonical body into tagged chunks, wire the full ingest
pipeline (extract → chunk → embed → store with status + chunk_count), and add a
one-shot command that seeds the four `resources/acceptatie` PDFs.

Purpose: This produces the retrievable corpus. Chunks must carry accurate
line_start/line_end/page so citations resolve against the canonical body, and
ingestion must be idempotent so re-runs are safe.

Output: `src/rag/{chunk,ingest}.rs`, `src/bin/ingest.rs`, and an ingested seed
corpus with `documents.status='indexed'` and non-zero `chunk_count`.
</objective>

  <name>Task 1: Token-aware chunker with line/page metadata</name>
  <files>apps/teun/service/src/rag/chunk.rs, apps/teun/service/src/rag/mod.rs</files>
  <behavior>
    - chunk_document on a known canonical body yields chunks whose concatenated content covers the source (modulo overlap).
    - For each chunk, line_start ≤ line_end, and line_start equals (count of '\n' before the chunk's byte offset)+1.
    - Each chunk's page equals page_of_line[line_start-1].
    - A body shorter than one chunk yields exactly one chunk spanning all its lines.
  </behavior>
  <action>
Create `src/rag/chunk.rs`. Implement `pub fn chunk_document(canonical: &Canonical, document_id: &str) -> Vec<Chunk>` using `text_splitter::TextSplitter` with `ChunkConfig::new(700).with_overlap(120)` and a `tiktoken_rs::cl100k_base()` sizer. Iterate the splitter's byte-offset+chunk API (RESEARCH Pattern 2): for each `(byte_off, chunk)` compute `line_start = canonical.text[..byte_off].bytes().filter(|&b| b==b'\n').count() + 1`, `line_end = line_start + chunk.bytes().filter(|&b| b==b'\n').count()`, and `page = canonical.page_of_line.get(line_start-1)` (clamp to last page if out of range). Build a `Chunk` (uuid id, given document_id, content=chunk string, line_start, line_end, page). Register `pub mod chunk;` in `rag/mod.rs`. Write the behavior-block unit tests against a hand-built `Canonical` (no PDF/network needed).
  </action>
  <verify>
    <automated>cd apps/teun/service && cargo test --package teun rag::chunk 2>&1 | tail -15</automated>
  </verify>
  <done>chunk_document exported; line_start/line_end computed from byte offsets; page read from page_of_line; short-body single-chunk case holds. RET-03 satisfied.</done>
